Dashboard por Mercado

Ganancia bruta, comisiones y ganancia neta por FIFO para cada par (USDT/PEN, USDT/USD…), sin mezclar monedas. Solo cuentan las operaciones completadas.

Sync API e Importación

Conecta Binance, Bybit o Bitget por API de solo lectura. Para OKX, El Dorado y otros, sube el archivo tal cual lo exporta el exchange: se detecta solo y no se duplica.

⚡

Registro en 5 Segundos

Botón flotante para anotar compra o venta al instante. Cada dato queda con su historial de cambios y su origen.

Calculadora de Spreads

Simula antes de ejecutar: ganancia neta, ROI, precio de equilibrio y escenarios por volumen.

Excel para tu Contador

Resumen por mercado, operaciones, ciclos, trazabilidad FIFO, comisiones, resultados por exchange y por mes, e incidencias. También CSV.

Bancos de tu País

Yape, Plin, BCP, Interbank, Mercado Pago, Pix, Nequi. Métodos de pago específicos por moneda fiat.
