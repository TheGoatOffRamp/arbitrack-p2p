2. Qué datos tratamos

  • Cuenta: email, nombre o razón social (opcional) y contraseña (guardada solo como hash, nunca en texto legible).
  • Operaciones: los datos de tus operaciones P2P que importas, sincronizas o registras: exchange, número de orden, fechas, montos, precios, comisiones, métodos de pago y el alias de la contraparte tal como figura en el exchange.
  • API keys de exchanges que decidas conectar, guardadas cifradas.
  • Datos técnicos: dirección IP y navegador de cada sesión, para seguridad.

3. Para qué los usamos

  • Prestar el servicio: calcular tus resultados, generar tus reportes y sincronizar con los exchanges que conectes.
  • Mantener la seguridad de tu cuenta (inicio de sesión, recuperación de contraseña, prevención de abusos).

No vendemos tus datos ni los usamos para publicidad. No compartimos tus operaciones con nadie, salvo obligación legal.

5. Seguridad

Las conexiones usan HTTPS, las contraseñas se guardan con un algoritmo de hash resistente (scrypt) y las API keys se cifran con AES-256. Cada cuenta solo puede ver sus propios datos. Te recomendamos conectar únicamente API keys de solo lectura.
